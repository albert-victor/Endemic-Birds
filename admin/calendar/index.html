Tour calendar – administration

This static site has no in-browser admin and no localStorage editor. Calendar data lives in content/tour-calendar.json and deploys with the site.

Update workflow today

  1. Edit content/tour-calendar.json in the repository.
  2. Run npm run validate:calendar.
  3. Run npm run build and deploy.
  4. Set updatedAt to the publish date.

Authenticated CMS

For secure updates and optional PDF uploads, follow the integration proposal in content/TOUR-CALENDAR-CMS.md (Cloudflare Access + Worker + R2, or Git-based CMS).

Do not add upload forms to this page without server-side authentication, file type limits and private object storage.
