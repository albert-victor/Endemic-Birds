# Safari package content

## Files

| File | Purpose |
|------|---------|
| `packages.json` | Core listing: duration, itinerary days, slugs (URLs preserved), SEO |
| `package-details.json` | Editorial overlays: why choose, habitats, route stops, banners |
| `package-editorial-audit.json` | Generated by `npm run audit:packages` – duplicates & missing days |
| `assets/downloads/packages/` | Owner PDF/DOCX per slug (optional) |

## Per-package download (optional)

On a package object in `packages.json`:

```json
"download": {
  "file": "assets/downloads/packages/14-days-southern-tanzania-birding-tour.pdf",
  "fileType": "pdf",
  "sizeBytes": 320000,
  "versionDate": "2026-03-01",
  "label": "Download full itinerary"
}
```

The site only shows a download button after the file responds to `HEAD`. Otherwise visitors see **Request the detailed itinerary**.

## Route map (opt-in only)

Route overview and map **do not** appear on package pages unless you set **`"showRouteMap": true`** on that slug in `package-details.json`. Use this only for flagship or special routes where a map adds clear value.

```json
"showRouteMap": true,
"routeStops": [
  { "stop": 1, "name": "Iringa hub", "lat": -7.769, "lng": 35.691, "dayFrom": 1, "dayTo": 2, "approximate": true }
],
"mapNote": "Approximate corridor for planning – verify on enquiry."
```

- Use **`dayFrom` / `dayTo`** when one location covers multiple itinerary days.
- Mark `approximate: true` for town-level coordinates; do not publish nest or sensitive species points.
- Map loads lazily (Leaflet + OpenStreetMap) when stops include `lat` / `lng`.

## Editorial audit (March 2026)

Re-run `npm run audit:packages` after itinerary edits. Known owner decisions:

1. **19-days-southern-tanzania-birding-trip** and **19-days-southern-endemic-birding** – identical itinerary text; clarify or merge.
2. **15-days-tanzania-birding-tour** and **15-days-birding-wildlife-photographic** – identical itinerary.
3. **20-day-endemic-birds-southern** vs **20-day-endemic-birding-tanzania** – different routes; confirm marketing copy.
4. **22-days-endemic-birding-tours** vs **22-days-birding-itinerary-north-east-south-pemba** – different; confirm distinction.
5. Multiple packages have **missing day numbers** in imported itineraries – do not invent days in JSON without owner sign-off.

Do not delete packages silently; use `needsOwnerReview` and on-page editorial banners.
